# Analysis plan

**Status:** not yet drafted.

This file will hold the pre-registered analysis plan for the study: the
research questions, the choice of site and ward frame, the treatment of the
Pimpri-Chinchwad and cantonment sites, and the specification of the spatial
models.

It is empty on purpose so that the plan can be written and timestamped before
the analysis is run. Until then, `README.md` describes the data and the
extraction, and `metadata/sources.csv` records what each source file is for.
